# 模型卡：Noname助手 Re:Play

## 基本信息

- **系统名称**：Noname助手 Re:Play（0.5.1）
- **系统类型**：面向 12—18 岁青少年的游戏行为心理支持对话原型
- **核心组件**：MI 状态机、双过程策略规划器、规则+语义风险识别、混合知识检索、LLM 回复生成、回复质量审核
- **模型依赖**：通过 OpenAI 兼容接口调用外部大模型；默认配置为 `gpt-4o-mini`，部署者可替换为其他兼容模型
- **训练数据**：本项目**不训练、不微调**模型；没有自建训练集

## 预期用途

- 帮助青少年理解游戏在生活中的作用、识别不喜欢的影响、由本人选择一个小改变实验；
- 提供风险识别、MI 风格对话、三天微实验与复盘；
- 作为比赛原型、教学演示和后续研究的工程基线。

## 明确不用于

- 医学或心理诊断、治疗、治愈承诺；
- 药物、剂量或临床处置建议；
- 紧急救援的唯一入口；
- 替代心理咨询师、精神科医生、学校心理老师或监护人；
- 对真实未成年人进行未经同意的数据采集或实验。

## 架构与决策依据

1. 规则层先做风险扫描，语义层只能提高风险；
2. 确定性 MI 分析保证模型不可用时仍能工作；
3. 双过程规划器选择本轮 MI 策略，LLM 负责语言生成；
4. RAG 只在需要时检索本地审核知识；
5. 质量审核拦截诊断、强迫、依赖、虚假救援、提示词泄露等严重问题；
6. 任何模型故障都降级到确定性安全回复。

## 评测

- 60 个确定性场景：60/60；
- 高风险路由：8/8；
- 行动计划形成：13/13；
- 透明规则基线：100.0 vs 37.4（离线确定性）；
- 后端测试：118 passed；
- 安全回归：26 个用例。

> 这些数字衡量工程与对话规则，不衡量临床疗效，也不代表在线模型在真实用户上的表现。

## 安全与伦理

- 高风险优先；不虚假报警、不承诺保密、不继续游戏建议；
- 程序化退出闸门，模型不能自行结束安全模式；
- 匿名会话、24 小时保留、一键清空；
- 不收集姓名、学校、地址、手机号、游戏账号等身份信息；
- 第三方模型供应商的数据保留、训练使用、跨境传输需由部署者审查；
- 正式上线前需完成未成年人数据保护影响评估、伦理审查、专业人员复核与危机升级流程。

## 已知局限

- 知识库仅 7 条，检索为词法级；
- 安全规则对委婉语和复杂语境的覆盖仍有限；
- 评测场景由团队编写，存在过拟合风险；
- 未开展真实用户研究和临床验证；
- 在线延迟受供应商影响；
- 年龄段适配刚接入提示词，尚未做分年龄效果评估。
