# 数据声明

## 1. 训练数据

本项目**不使用自建训练数据，不微调模型**。系统的对话能力来自部署者配置的 OpenAI 兼容大模型；项目自身提供的是状态机、规则、知识库、提示词、场景集与评测代码。

## 2. 知识库数据

`knowledge/reviewed/core.json` 当前包含 7 条专家审核条目：

- 3 条含公开来源 URL（WHO 游戏障碍问答、UNICEF Safer Chatbots、UNICEF 儿童 AI 政策指南）；
- 4 条标注为项目专家审核条目，用于睡眠、归属、学习逃避与 MI 自主支持；
- 每条包含标题、类别、关键词、摘要、建议动作、来源名称与审核状态字段。

知识库不是医学指南，不能替代专业判断；正式上线前需由具备资质的专业人员逐条复核并记录版本。

## 3. 评测场景

`evaluation/scenarios/core.json` 与 `extended.json` 共 60 个场景，全部为项目团队编写的**虚构对话**，用于工程验收：

- 不包含真实未成年人对话、姓名、学校、地址、账号或联系方式；
- 高风险场景只用于验证安全路由，不代表真实个案；
- 场景与期望由团队编写，存在“自己出题自己考”的效度风险；下一阶段需加入 held-out 场景、独立红队和专家盲评。

## 4. 运行时数据

- 会话使用随机匿名 ID，不要求注册；
- 默认 SQLite 存储，24 小时后自动清理；可切换为纯内存；
- 用户可随时通过 `DELETE /api/sessions/{session_id}` 清空会话；
- 不主动收集姓名、学校、班级、地址、手机号、身份证件、游戏账号、照片、音频或视频；
- 配置外部模型后，用户输入会发送到所配置的供应商；部署者必须审查其数据保留、训练使用、跨境传输和未成年人条款；
- 日志只记录会话 ID 前缀、阶段、风险、策略、耗时等运行信息，不记录 API Key；演示前应清理日志与临时截图中的敏感信息。

## 5. 伦理与同意

- 本阶段未开展真实未成年人用户研究；
- 若开展问卷、访谈或可用性测试，必须取得监护人同意与参与者本人同意，说明目的、数据范围、保留期和撤回方式；
- 所有材料匿名化；不记录可直接识别身份的信息；
- 研究前完成伦理审查；高风险表达按安全规范转介现实支持，不作为研究数据继续追问。

## 6. 数据分发与复现

- 仓库不包含 `.env`、API Key、SQLite 数据库、`node_modules` 或构建产物；
- 评测结果 JSON 可复现，但会受运行时间与机器性能影响；
- 在线评测结果受模型版本、供应商、网络和采样随机性影响，应记录模型名称、日期、失败重试和人工复核范围。

## 7. 联系与更正

如发现数据、来源或安全规则问题，请在仓库 Issue 中记录：复现输入、期望行为、实际行为、影响范围。修复后应补充回归测试并更新本声明。
