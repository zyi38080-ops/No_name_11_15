# 匿名问卷设计（待执行）

## 目的

回答四个问题：

1. 青少年自己如何描述“游戏带来的影响”，与家长/学校的归因有何差异？
2. 哪些情境最难停下来（队友、排位、情绪、习惯）？
3. 他们愿意向谁求助，什么会让他们不愿意求助？
4. 什么样的支持方式（对话、三天实验、记录、同伴）最可接受？

## 对象与抽样

- 12—18 岁青少年；匿名；不收集姓名、学校、地址、联系方式、游戏账号。
- 目标样本 n≥100；通过学校、社区或青少年活动场所招募，取得场所许可与监护人同意。
- 分层：12—14 / 15—16 / 17—18 三个年龄段尽量均衡；男女与其他性别认同均纳入。
- 排除：正在经历急性危机者不纳入问卷；如出现高风险表达，按安全规范转介，不作为研究数据分析。

## 问卷（10 题以内）

1. 你的年龄段：12—14 / 15—16 / 17—18。
2. 上学日平均游戏时间：不玩 / 少于1小时 / 1—2小时 / 2—3小时 / 3小时以上。
3. 周末平均游戏时间：不玩 / 少于1小时 / 1—2小时 / 2—3小时 / 3小时以上。
4. 你是否曾经希望少玩一点：从来没有 / 偶尔 / 经常 / 一直。
5. 最难停下来通常是因为（可多选）：队友还在线 / 输了想翻盘 / 赢了想继续 / 无聊 / 压力大 / 习惯了 / 其他。
6. 游戏对你来说主要给了什么（可多选）：放松 / 成就感 / 和朋友一起 / 暂时逃离压力 / 自己决定 / 其他。
7. 你注意到游戏带来过哪些影响（可多选）：睡眠 / 学习 / 和父母的关系 / 情绪 / 朋友关系 / 没有明显影响。
8. 如果想找人聊，你更愿意找：父母 / 朋友 / 老师或心理老师 / 网络上的陌生人 / 谁也不找。
9. 什么样的 AI 助手会让你不信任（可多选）：一上来就说教 / 让我立刻戒掉 / 监视我 / 给我贴标签 / 收集我的信息 / 其他。
10. 你最希望大人先理解你哪一点？（开放题，限 100 字）

## 分析计划

- 对 1—9 题做描述统计与年龄段交叉表；不把相关性解释为因果关系。
- 对第 10 题做双人主题编码，形成 5—8 个主题；记录编码分歧与解决方式。
- 将结果映射到需求—功能—指标追溯表；不把问卷结果当作临床证据。
- 报告样本量、招募方式、缺失值、局限；不报告可识别个人的信息。

## 伦理

- 未成年人需监护人同意与本人同意；可随时退出。
- 匿名、最小化、加密存储、限期删除；不记录 IP 或设备标识。
- 研究前完成伦理审查；高风险表达按 `docs/safety.md` 处理。
